# test-infra-definitions

> **This repository no longer contains the test-infra-definitions framework.**

The core code has been moved into the [datadog-agent](https://github.com/DataDog/datadog-agent) repository, under [`test/e2e-framework`](https://github.com/DataDog/datadog-agent/tree/main/test/e2e-framework).

## What remains here

This repository now only hosts application code (under `apps/`) used as workloads in e2e tests — container images, sample services, and supporting utilities that are deployed during test runs.
